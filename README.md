I lead the Technology Lab at **La Silla Vacía**, a nonprofit political journalism outlet in Colombia. We build AI-powered tools and data infrastructure that help a newsroom work faster, reach more readers, and sustain itself.

I'm a self-taught engineer who enjoys owning a product end to end, from the database schema to the last pixel of the UI.

### What I'm working on

- **Revenue-first CRM.** Unifies payments (Stripe, Wompi), WooCommerce orders, email metrics and funnel events into one view, with an in-house analytics SDK.
- **Headless content layer.** A fast API and visual editor that sits between WordPress and the mobile app, with push notifications and audience analytics.
- **Agentic newsroom tooling.** Multi-agent pipelines that monitor sources, draft stories, and pass every claim through an editor agent that verifies it.
- **[Aria](https://github.com/i-montes/aria).** My personal desktop AI assistant, written in Rust.

### Open source

**AI agents**

| Project | Description | Stack |
| --- | --- | --- |
| [**aria**](https://github.com/i-montes/aria) | Personal desktop assistant for Omarchy/Hyprland. Opens a dock over your work with a shortcut; per-tab sessions, sandboxed commands, background and scheduled jobs, connectors, memory, keyring-stored keys and local voice dictation. | Rust |
| [**aria-extension**](https://github.com/i-montes/aria-extension) | Chrome extension (Manifest V3) that lets Aria read, click, fill forms and take screenshots in the browser through a native messaging host and a token-protected local server, plus an `aria-browse` CLI. | JavaScript |
| [**herdr-web-service**](https://github.com/i-montes/herdr-web-service) | Self-hosted web client for Herdr coding agents (Claude Code, OpenCode). Chat with your sessions from any device, review diffs and answer prompts; argon2id auth, HTTPS and tunnel access. | TypeScript · Bun |
